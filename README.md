# Algebra 2 Unit 1: Test Prep

An interactive study page for Pre-AP Algebra 2, Unit 1 (polynomials, power functions and quadratic equations).

- **Learn:** 10 topics, each with a rule, a worked example shown one step at a time and a quick check
- **Review sheet:** 12 questions with full working
- **Extra practice:** unlimited randomly generated questions in 17 skills
- **Test:** unlocks once every topic is ticked; 20 fresh questions, a score, and the working for anything you got wrong
- **Tools:** a whiteboard to draw your working on and a built-in calculator, available on every tab

Open `index.html` in a browser. It is a single file and works offline.
